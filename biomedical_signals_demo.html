🧠 Biomedical Signal Processing Visualization

📊 Interactive Demo

This is a demonstration of the biomedical signal visualization tool created for the Quasar Coding Challenge.

The actual visualization would show:

  • EEG Signals (µV scale): 21 channels including Fz, Cz, P3, C3, F3, F4, C4, P4, Fp1, Fp2, T3, T4, T5, T6, O1, O2, F7, F8, A1, A2, Pz
  • ECG Signals (mV scale): X1:LEOG (Left ECG) and X2:REOG (Right ECG)
  • CM Reference: Common Mode reference signal (large amplitude, separate scale)

🎯 Features Implemented

  • Multi-axis scaling: EEG (µV), ECG (mV), CM (separate scale)
  • Interactive controls: Scroll, pan, zoom, hover
  • Range selector buttons: 1s, 5s, 10s, 30s, All
  • Channel toggle: Click legend to show/hide channels
  • Export functionality: PNG and HTML export
  • Range slider: Bottom navigation panel
  • Hover information: Detailed signal values and timing

🚀 How to Run the Full Visualization

  1. Ensure Python is installed
  2. Install dependencies: pip install pandas plotly numpy
  3. Run the main script: python plot_signals.py
  4. Or use advanced features: python plot_signals_advanced.py --help
